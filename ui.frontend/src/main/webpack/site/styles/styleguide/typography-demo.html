Implementation Notes

Font Loading

To use this typography system, you'll need to load the Malik and Averta STD PE fonts. Add the following to your HTML head:

<link href="https://fonts.googleapis.com/css2?family=Malik:wght@800&display=swap" rel="stylesheet">
<link href="https://fonts.googleapis.com/css2?family=Averta+STD+PE:wght@400;600;700&display=swap" rel="stylesheet">
SCSS Import

Import the typography styles in your main SCSS file:

@import 'styles/styleguide/typography';
Responsive Behavior

All typography classes automatically adjust for different screen sizes. The system uses mobile-first responsive design with breakpoints at 768px (tablet) and 1024px (desktop).
